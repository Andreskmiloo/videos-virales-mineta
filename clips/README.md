# clips/

Una carpeta por guion, con el mismo nombre que el `id` del guion:

```
clips/2026-11-21_goalkeepers-main-character/
    5.mp4  4.mp4  3.mp4  2.mp4  1.mp4
```

- Formatos: .mp4 .mov .mkv .webm .m4v — horizontal o vertical, da igual.
- Corta solo el momento (5–10 s). Si el clip es más largo, pon `start`/`end` en el guion.
- `python main.py check` te dice qué falta.
- Esta carpeta NO se sube a git (los clips se quedan en tu PC).
